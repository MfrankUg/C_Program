## ▶️ How to Run

### 1. Check if GCC is installed

```bash
gcc --version
```

### 2. Compile a C program

```bash
gcc main.c -o main
```

### 3. Run the program

On Windows:

```bash
./main
```

or:

```bash
main.exe
```

### Example

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");

    return 0;
}
```

Compile:

```bash
gcc main.c -o main
```

Run:

```bash
./main
```

Learning C provides a strong foundation for understanding how computers work.

It helps develop an understanding of:

* Memory management
* Variables and data representation
* Pointers
* Algorithms
* Program execution
* Compilation
* Low-level programming concepts
* Problem-solving

The concepts learned in C can also make it easier to understand other programming languages such as C++, Java, C#, and others.
